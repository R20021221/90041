# RULER.md - IMMUTABLE PROJECT RULES

This file is a project rule file. Do not edit, delete, rename, or override it unless the user explicitly says so.

## Mandatory Rules

1. Every modification must be recorded so work can be traced and reverted.
2. Every conversation update must be summarized concisely in `MEMORY.md`.
3. After each completed task, update `PROGRESS.md`.
4. Before writing or changing code, briefly tell the user the planned edit direction and key logic points.
5. If unsure, stop and ask the user first; also reread the relevant `.md` files before continuing.
6. `requirement.docx` is the original official requirement file. It is read-only and must never be modified.
7. Use `requirement.docx` only when Markdown files miss details and only after the user agrees it is needed.
